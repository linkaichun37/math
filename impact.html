Finding the missing idea behind a wrong answer.

Math Gap Finder is Casey Lee’s ongoing experiment in diagnostic tutoring: can software identify the first prerequisite gap in a student’s work and teach that idea before showing a final solution?

Try the prototypeJoin the feedback study

The observed problem

Students can fail a calculus step for a reason that began years earlier: factoring, function notation, signs, fractions, or trigonometry. A correct final answer does not locate that earlier break in understanding.

The design hypothesis

If a tutor first transcribes the problem, independently verifies the mathematics, compares the student’s work, and identifies the earliest questionable step, its feedback should be more useful than an answer-only system.

Evaluation plan

No impact number is displayed until it has real evidence behind it. The next study will use a teacher-reviewed set of problems and anonymized student feedback.

  1. Create a balanced benchmark across algebra, limits, derivatives, integrals, parametric equations, series, and statistics.
  2. Have a teacher label the correct question transcription, final answer, and first misconception.
  3. Measure transcription accuracy, final-answer accuracy, first-gap agreement, response time, and student helpfulness ratings.
  4. Analyze failures by handwriting quality, topic, language, and problem complexity.
  5. Publish the sample size, rubric, and results—including failures—on this page.

Current limitations

The AI can misread symbols and can still calculate incorrectly. Browser-only profiles are not real accounts. The Cloudflare build needs durable server-side rate limiting before a large public launch. The five-question placement check is an orientation tool, not a validated assessment.
